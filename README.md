# FutureTech Radar

A Next.js web application that crawls live technology news, business articles, and academic research breakthroughs across 16 key future technologies—ready to deploy on **GitHub + Vercel** with zero API keys required.

## Covered Technologies
- Quantum Computing
- Neuromorphic Computing
- Generative & Agentic AI
- Hyperautomation
- Autonomous Vehicles
- Battery Technologies
- Synthetic Biology
- Brain-Computer Interfaces (BCIs)
- Digital Trust Technologies
- Zero-Latency Connectivity
- Voice-Activated Technology
- Nuclear Fusion
- Preventive Medicine & Wellbeing
- Climate Tech
- Space Exploration
- Nanotechnology

## Run Locally
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, and import your GitHub repo.
3. Click **Deploy** (no environment variables needed).
